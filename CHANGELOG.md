## 1.0.0

### Major Changes

- # Frontend Technology Stack

  Built with **React 19**, **TypeScript**, and **Vite 8**.

  Package Purpose

  ***

  **Tailwind CSS v4** Utility-first styling
  **shadcn/ui** Reusable, accessible UI components
  **ESLint** JavaScript and TypeScript code linting
  **Stylelint** CSS and stylesheet linting
  **Prettier** Consistent code formatting
  **Husky** Git hooks automation
  **lint-staged** Runs checks on staged files
  **Commitlint** Enforces consistent commit messages

  **Quality workflow:** ESLint, Stylelint, and Prettier maintain code
  quality and consistency. Husky and lint-staged run pre-commit checks,
  while Commitlint validates commit messages.
